About the data

Methodology and limitations

Independent experimental reconstruction—not official GLA statistics. This project was prompted by the aim of making withdrawn public data easier to explore. It is not affiliated with or endorsed by the Greater London Authority. Its data, classifications, calculations and visualisations are provided without warranty or claim of accuracy, completeness or fitness for a particular purpose.

Source data: Greater London Authority, Planning London Datahub. The GLA cannot warrant the quality or accuracy of the source data. Do not rely on this dashboard for statutory monitoring, planning decisions, financial decisions or other consequential uses. Check figures against the GLA's source material, London Plan Annual Monitoring Reports and the underlying Planning London Datahub records.

What is counted

The importer reads self-contained residential-unit entries nested inside PLD application records. A unit with an actual completion date in the selected financial year contributes +1, except a unit marked as a loss, which contributes −1.

This is a project-defined reconstructed net count. It excludes other residential accommodation and non-permanent dwellings, so it is not the complete London Plan housing-supply measure. The displayed Units LP2021 value is currently identical to the basic net-unit value; the former dashboard's adjustment has not been reconstructed.

How records are classified

Affordability is inferred from tenure text. Unit types are lightly normalised. Use class is inferred from unit type and is not an authoritative planning use-class field. Unknown and unrecognised values are retained where possible.

What a detail row means

Detail rows are grouped by address text, authority, financial year, affordability, unit type and inferred use class. They are not application-level records and have no stable planning-application identifier. Unrelated developments with identical grouping values may be combined, while one development may appear in several rows.

Targets and comparisons

The London-wide target values are contextual references shown only for an otherwise unfiltered All London selection. Because the completion count excludes non-conventional supply, the percentage is indicative rather than a statutory assessment.

Historical comparisons show material differences from figures recorded during reconstruction. Automated validation checks the internal consistency of the published files; it does not establish that the source data is complete or correct, or that this calculation is equivalent to the former dashboard.

Source and updates

The static snapshot is derived from the public Planning London Datahub API and is intended to be rebuilt weekly. PLD is a changing operational database and historic values can be revised after the period concerned. A failed update leaves the previous snapshot online.
