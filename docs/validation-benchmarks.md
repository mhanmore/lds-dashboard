# Validation benchmarks

The following London-wide net self-contained completion totals are the regression benchmarks specified for the project:

| Financial year | Published total |
|---|---:|
| 2019/20 | 37,843 |
| 2020/21 | 30,703 |
| 2021/22 | 37,524 |
| 2022/23 | 32,053 |
| 2023/24 | 31,629 |

The build pipeline should compare live output with these values before a baseline is replaced. Until the PLD schema and the GLA calculation rules are confirmed, validation is intentionally conservative and the checked-in sample uses these figures as display data.
