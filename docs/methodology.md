# Methodology

Live artifacts are generated by `npm run build:data` from the public, read-only Planning London Datahub (PLD) API. The import queries PLD only at build time, then publishes borough-year aggregates plus compact site summaries. The browser reads this local artifact and never queries PLD as filters change. A manual “Check for data update” request can check a deployed worker for a newer published artifact.

The measure is net self-contained residential completions, allocated to the financial year containing each unit's `actual_completion_date`. PLD records one row per dwelling: a `Loss` counts as -1 and every other completed dwelling as +1. Affordability is derived from the unit tenure and dwelling type from the unit type; unknown values are retained rather than discarded. The displayed use class is explicitly an inference from unit type: HMO records are grouped as C4, standard self-contained dwelling types as C3, and student, co-living, communal and other types as other residential. It is not a source use-class field.

This is deliberately not presented as the full London Plan housing-supply measure. City Hall defines that target measure as conventional completions plus non-conventional completions (for example hostel and halls bedrooms). This dashboard currently imports only PLD `residential_units`, not its other residential-accommodation or non-permanent-dwellings records. Consequently the London-wide target comparison is only displayed with no borough or tenure filter, and should be treated as indicative rather than a statutory monitoring result.

The PLD field mapping is deliberately isolated in `scripts/build-data.mjs`. The importer requests each financial year separately, reducing load and avoiding silent truncation at Elasticsearch's standard 10,000-result window. It fails rather than publishing a partial year if that limit is reached. Site rows are grouped by address, authority, financial year and affordability; authority-year summaries retain the affordability and dwelling-type cross-tab needed for instant filters.
