# Methodology

The checked-in artifact is a small demonstration dataset so the static site can be previewed without API credentials. Live artifacts are generated by `npm run build:data` and must be validated before publication.

The intended measure is net self-contained residential completions, allocated to financial years. `Units LP2021` is retained as the dashboard's adjusted unit measure when supplied by PLD; otherwise the pipeline falls back to net units and then raw units. Unknown affordability and dwelling type values are retained rather than discarded.

The PLD field mapping is deliberately isolated in `scripts/build-data.mjs`. Confirm the API documentation and field names before configuring `PLD_EXPORT_URL`; do not use the demo artifact as a published historical estimate.
